## How to add an entry

- **Decided:** `| D# | date | decision in one line | why in one line |`
- **Open:** `| Q# | question | milestone that needs it | safe default | User / DM / Agent |`
- Never delete entries. If a decision changes, add a new D# that says "Replaces D#". Answered questions stay in the list, struck through, with a pointer to the D#.
